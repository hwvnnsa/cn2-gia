## 下单流程与避坑点

流程本身不难：选套餐和机房 → Add to Cart → 填优惠码（当前留空）→ 注册登录 → 付款 → 几分钟内自动开通，进 KiwiVM 面板拿 root 密码和管理机器。有几件事容易踩坑：

- **认准官方站点**。官网右上角是 Client Area 和 Register 按钮，页面底部有 IT7 Networks 的版权信息。带“搬瓦工中文网”之类字样的中文站都是第三方，官方主域名在国内部分地区访问不稳定，官方提供多个备用镜像域名，账号数据互通。任何让你输入账号密码或直接付款的中文“官网”都不要信。
- **注册信息填真实的**。姓名、邮箱、国家要与实际一致，不一致的订单可能被系统标记为欺诈订单。
- **流量按月结算**。当月流量用超额会停机，下个月自动恢复，跑大流量任务前先看一眼面板里的用量。
- **余额充值有限制**。支付宝可以直接买 VPS，但给账户余额充值只支持 PayPal 或信用卡，想充值再消费的话注意这个区别。

## 常见问题

**循环折扣码续费时还有效吗？** 有效。用码下单后，之后每次续费都按折扣价结算，这是搬瓦工优惠码和很多商家“仅首单折扣”的区别。当然前提是码本身没被官方取消。

**续费会涨价吗？能一次买多年吗？** 续费按常规价格，没有首年低价、次年涨价的套路。但也不支持一次买多年，到期后一周内系统生成新账单并邮件通知，按时续费即可。

**IP 被封了怎么办？** 控制面板里有付费换 IP 服务，每次 8 美元上下，以面板实际显示为准。

**限量版套餐是什么？** 搬瓦工会不定期上架配置相同但便宜 40%–60% 的限量方案，库存极少，经常几小时内售罄，也没有固定补货时间。比如历史上出现过 $19/年的 1 核 1G 方案（弗里蒙特机房、普通线路），以及 $39/年起步、回程走电信 CN2 GIA 加移动 CMIN2 的 Box 系列——后者对移动用户尤其友好，可惜长期缺货。真想蹲限量版，关注补货通知比蹲优惠码更实际。
